Auto-update

The desktop app checks for updates automatically. You can also trigger it manually from the launcher's "Updates" tab.

On launch, the app compares your installed version with the latest release. If a newer version is published, you get a notification with a one-click "Download & Install" button. The download is verified via SHA-256 before running.

  • Updates are pulled from GitHub Releases (primary) and Cloudflare R2 (CDN mirror)
  • SHA-256 checksum verified before install
  • Mandatory updates (rare, security-critical) auto-block until user accepts
  • Manual check available any time via the launcher's "↻ Updates" tab
